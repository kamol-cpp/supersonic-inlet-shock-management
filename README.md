# Shock Management in Supersonic Engine Inlets

**Status:** Completed · March–May 2026  
**Area:** Aerospace analysis, compressible flow

A poster comparing variable-geometry and fixed diverterless supersonic inlets for shock control, pressure recovery, and compressor inflow.

## Main tradeoff

Variable geometry offers more active shock control and off-design adaptability, with added mass and mechanical complexity. Diverterless bump inlets simplify the mechanism and redirect low-energy boundary-layer flow, but offer less control across the Mach range.
